**Edit the code in your local development environment**

Any change pushed to the repo will also be reflected in the Base44 Builder.

**Prerequisites:** 

1. Clone the repository using the project's Git URL 
2. Navigate to the project directory
3. Install dependencies: `npm install`
4. Create an `.env.local` file and set the right environment variables

```
VITE_BASE44_APP_ID=your_app_id
VITE_BASE44_APP_BASE_URL=your_backend_url

e.g.
VITE_BASE44_APP_ID=cbef744a8545c389ef439ea6
VITE_BASE44_APP_BASE_URL=https://my-to-do-list-81bfaad7.base44.app
```

Run the app: `npm run dev`

## Deploy no GitHub Pages

1. Configure o repositório no GitHub.
2. Rode `npm run deploy` para publicar a pasta `dist` na branch `gh-pages`.
3. No GitHub, em Settings > Pages, selecione a branch `gh-pages` como origem do site.

O app foi ajustado para usar HashRouter, então as rotas funcionam no GitHub Pages sem precisar de fallback do servidor.

**Publish your changes**

Open [Base44.com](http://Base44.com) and click on Publish.
